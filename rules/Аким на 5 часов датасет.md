### Синергии

Бонус применяется, если выбраны обе меры. Для районных мер бонус относится к району первой меры пары и не масштабируется лагом.

| Пара | Бонус |
|---|---|
| M1 + M2 | T1 +2 в районе M1 |
| M10 + M12 | B1 +2 в районе M10 |
| M5 + M6 | E2 +2 в районе M5 |

### Несовместимости

- M1 и M3 несовместимы в любых районах.
- M4 и M7 нельзя выбирать для одного района: конфликт за участок.
- M5 и M13 нельзя выбирать для одного района: дублирование программы.

## 3. Формула Score

1. Для каждого района и показателя сложить базовое значение, реализованные эффекты и синергии; затем ограничить результат диапазоном 0–100.
2. Балл района — сумма показателей, умноженных на их веса.
3. Городской средний балл — средневзвешенное по долям населения.
4. Итог: Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit, где N_crit — число пар «район × показатель» со значением строго меньше 40.

Базовый Score без действий — 52.56 (0.7 × 56.86 + 0.3 × 49.18 − 2).

Контрольный допустимый набор: M7 в Нуре, M8 в Нуре, M10 в Нуре, M12 для города, M5 в Сарыарке. Стоимость — 95; ожидаемый Score ≈56.5 (+4.0 к базе). Синергия M10 + M12 применяется в Нуре.

## 4. Правила выбора

- Бюджет — 100 условных единиц, остаток не даёт бонуса.
- Нужно выбрать ровно 5 разных мероприятий; каждое мероприятие выбирается не более одного раза.
- Для районной меры район обязателен; для городской район не указывается.
- Не более двух мер одного направления.
- Любое нарушение делает набор невалидным; валидатор должен возвращать причину.
- Порядок решений не влияет на результат.
